# Verification evidence

Record actual commands, environment, tested commit and results for each task. Scaffold checks do not satisfy domain acceptance criteria or human gates. Keep real credentials, cookies, private payloads and generated browser profiles out of evidence and Git.

The [G1 foundation record](R1-G1-A-foundation.md) records accepted integration and preserves pre-acceptance remediation/failed audit history. Its JSON snapshots retain their original states. The [F-01 record](R1-A01-auth.md) covers the new auth/team increment's actual clean-clone/API/browser checks; its peer acceptance remains pending.
